# dol-check

돌마켓에서 설치한 스킬 본문이 현재 대화에 로드되는지 확인하는 진단 플러그인이다.
업무용 기능을 제공하거나 시스템 상태를 조사하는 도구는 아니다.
별도의 계정, API 키, 외부 프로그램, 네트워크 연결 설정은 필요 없다.

Claude Code에서는 돌마켓 등록 후 `claude plugin install dol-check@dol-market`로 설치한다.
새 세션을 열고 `/dol-check:check`를 호출한다.
Codex에서는 돌마켓의 dol-check를 설치하고 새 대화에서 check 스킬을 선택한다.

기대 응답은 `돌마켓 스킬 로딩 확인: dol-check / check / 0.1.0`이다.
이 결과는 현재 본문의 로딩만 확인한다.
원격 저장소 연결, 자동 업데이트, 다른 스킬의 실행 성공, 다른 호스트의 호환성까지 확인한 것으로 해석하면 안 된다.
파일 수정이나 도구 실행은 수행하지 않는다.
라이선스는 MIT다.
